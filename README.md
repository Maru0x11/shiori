# Shiori

A keyboard-first document reader designed for immersive reading on Linux.

> **Status:** Early development — currently more of a learning project than a production-ready application.

## Vision

Shiori aims to be a modern document reader built specifically for language learning, with a focus on:

* Vim-inspired navigation
* Native popup dictionaries and lookups
* Beautiful typography, especially for Korean
* EPUB and PDF support
* An extensible document-rendering architecture
* A distraction-free reading experience

## Current Progress

### Phase 1

* [ ] Render an EPUB
* [ ] Basic Vim navigation (`j`, `k`, `gg`, `G`)
* [ ] Popup dictionary and word lookups

### Future

* [ ] PDF support and OCR
* [ ] Full-text search
* [ ] Bookmarks
* [ ] Anki integration
* [ ] Remember reading position
* [ ] Multilingual support

## Why?

For a long time, I've been looking for a local document reader specifically designed for language learning. I haven't found one that fits what I want, so I decided to build my own.

The goal is to make reading immersion material feel enjoyable rather than overwhelming,a reader where language-learning features are built into the reading experience instead of being bolted on afterward.
