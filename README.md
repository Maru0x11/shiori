# shiori

A keyboard-first document reader designed for immersive reading on Linux.

> **Status:** Early development (For now it's more of a learning project than a production-ready project)

## Vision

Shiori aims to be a modern document reader focused on:

- Vim-inspired navigation
- Native popup dictionaries
- Beautiful typography (Japanese mainly)
- EPUB and PDF support
- Extensible document renderer architecture
- A distraction-free reading experience
